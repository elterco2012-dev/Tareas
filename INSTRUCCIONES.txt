ORGANIZADOR PERSONAL - SOLO GITHUB

1) En GitHub crea un repositorio PUBLICO, por ejemplo "organizador-web".
2) Sube al directorio raiz de ese repositorio: index.html, manifest.webmanifest, sw.js y la carpeta icons/ completa
   (los cuatro son necesarios para instalarla como aplicacion y abrirla sin conexion).
3) Settings > Pages > Build and deployment: Deploy from a branch, main, /(root). Guarda.
4) Crea OTRO repositorio, PRIVADO, por ejemplo "mis-tareas-datos". No necesitas subir archivos.
5) En GitHub: Settings de tu cuenta > Developer settings > Personal access tokens > Fine-grained tokens > Generate new token.
   - Repository access: Only select repositories > mis-tareas-datos.
   - Repository permissions > Contents: Read and write.
   - Define una caducidad razonable; deberas renovarlo cuando venza.
   - NO compartas el token, ni lo subas al repositorio publico, ni lo pegues en conversaciones.
6) Abre la URL de GitHub Pages (https://TU_USUARIO.github.io/organizador-web/).
7) Toca el boton de estado (arriba a la derecha) para abrir Sincronizacion; escribe usuario, nombre del repo PRIVADO
   y token, y pulsa Guardar conexion.
8) Abre la misma URL desde tu celular y configura los mismos datos una sola vez.

INSTALAR COMO APLICACION
- Android (Chrome): abri la URL > menu ⋮ > "Instalar aplicacion" (o "Agregar a pantalla principal").
- iPhone (Safari): abri la URL > boton Compartir > "Agregar a inicio".
- Compu (Chrome/Edge): icono de instalar en la barra de direcciones, o menu > "Instalar Mis tareas".
- En iPhone la app instalada no comparte datos con Safari: al abrirla por primera vez desde el icono,
  carga de nuevo usuario, repositorio y token en Sincronizacion. Usa siempre la app instalada (no Safari)
  para cargar tareas: lo que cargues en Safari sin conexion a GitHub no aparece en la app.

USO DIARIO
- Abris la app, escribis la tarea y Enter: queda para hoy. Con los botones Mañana, Lunes o Sin fecha elegis otro dia.
- Texto libre: "Llamar proveedor viernes !alta @Juan" carga la fecha, la prioridad y quien la pidio.
  Fechas: hoy, mañana, pasado mañana, lunes a domingo (el proximo), 15/10, en 3 dias. Prioridad: !alta (o !), !media, !baja.
  Debajo del campo aparece "Detectado: ..." con lo que se va a cargar.
- Toca la casilla redonda para terminar una tarea, el texto para editarla, o "⋯" para pasarla a hoy, mañana o el lunes, o borrarla.
  Despues de terminar, reagendar o borrar aparece "Deshacer" por unos segundos.
- La tarea queda guardada en el dispositivo al instante: podes cerrar la app enseguida.
  Se sube a GitHub sola; si no habia señal, se sube la proxima vez que abras la app.
  El boton de arriba a la derecha muestra el estado ("Al dia", "Pendiente", "Sin subir") y abre la configuracion de GitHub.
- En la compu hay atajos de teclado: N nueva, / buscar, flechas para elegir, Espacio terminar, E editar, H hoy, M mañana, Supr borrar.

SEGURIDAD Y LIMITACIONES
- La pagina HTML es PUBLICA. El repositorio de datos es PRIVADO.
- El token se guarda en localStorage en CADA navegador para evitar volver a ingresarlo. No es adecuado para dispositivos compartidos ni informacion confidencial empresarial. Un script malicioso, extension comprometida o persona con acceso al navegador podria extraerlo.
- NO pongas el token en index.html ni en commits de GitHub.
- Si el token se filtra, revocalo inmediatamente en GitHub.
- GitHub Pages no es una plataforma de autenticacion privada; la seguridad de los datos depende de los permisos del repositorio y del token.
- La aplicacion consulta cambios cada 20 segundos mientras esta abierta. Sin Internet se puede abrir y cargar tareas;
  los cambios quedan guardados en el dispositivo hasta que vuelva la conexion.
- Cada cambio crea un commit en el repositorio privado. Si dos dispositivos guardan al mismo tiempo, se reintenta solo.
- "Borrar conexion y datos de este dispositivo" (en Sincronizacion, pide confirmar con un segundo toque) borra la copia local de las tareas (avisa si habia cambios sin subir).
- Borrar una tarea la saca de tareas.json. Si te arrepentis despues del "Deshacer", sigue en el historial de commits del repositorio privado.
- En Terminadas se ven las de los ultimos 7 dias; "Ver todas" muestra el resto.
- Comprueba las politicas de tu empresa antes de introducir informacion laboral en un servicio externo.
